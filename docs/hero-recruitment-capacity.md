# 英雄招募容量获取说明

本文说明玩家艾查恩在单人超凡帝国新战役中的英雄容量来源，涵盖 28 种普通英雄、合计 46 个法术系及其他子类型。主模组、外部英雄模组和容量测试包的效果分别列出；塔木尔可汗的六位氏族长另列于文末。

## 容量如何计算

正式玩法沿用六种共享容量。招募页按具体英雄种类显示分类，同种英雄的不同法术系放在一起，但分类本身不会把共享额度拆开。

| 共享容量 | 使用这份额度的英雄 |
| --- | --- |
| 冠军类 | 神尊英雄、恐虐神尊英雄、纳垢神尊英雄、奸奇神尊英雄、色孽神尊英雄、巨角公牛、巨身狼人、半人牛陶鲁克 |
| 法师类 | 混沌术士、纳垢混沌术士、奸奇混沌术士、色孽混沌术士、嘶叫萨满、巫术萨满、恶魔铁匠术士 |
| 使节类 | 鲜血收割者、沼栖妖降灾使、纳垢狂信徒、奸奇狂信徒、色孽狂信徒 |
| 符文匠类 | 沼栖妖贵族、恐虐狂信徒、虹光惧妖、杜鲁齐受祝者 |
| 密探类 | 战角兽、瘟疫使徒 |
| 工程师类 | 炼狱堡主、魅魔侍女 |

这些名称用于说明共享关系。例如，增加巨角公牛的冠军类容量，也能让神尊英雄使用这份额度；增加炼狱堡主的工程师类容量，也能让魅魔侍女使用。

以下建筑表统一按这几条规则阅读：

- 数值是**单座完好建筑对全派系对应共享容量的贡献**，不是直接赠送英雄。
- 罗马数字表示建造所需的主城或营地主建筑等级，不是建筑名称中的级数。
- 升级后的数值替换旧建筑贡献。例如「冰川通路 +2」就是总共 +2，不与升级前各级相加。
- 不同城镇、不同营地的有效建筑可以叠加。同一英雄的多个法术系不会让一座建筑重复提供容量。
- **容量与招募解锁分别计算。**仍需满足对应建筑、科技、候选池、费用及原有获取条件；有空余容量不代表能在所有地方招募该英雄。

## 混沌勇士：9 种英雄

这部分保留原版建筑容量：

- **勇士建筑：**Ⅱ「战士小屋」→ Ⅲ「警卫兵营」→ Ⅳ「勇士大厅」，每座当前建筑提供冠军类容量 **+1**。
- **神龛建筑：**Ⅱ「混沌神龛」→ Ⅳ「萨满寺庙」→ Ⅴ「亵渎圣所」，每座当前建筑提供法师类容量 **+1**。

| 英雄 | 法术系 | 容量来源 |
| --- | --- | --- |
| 神尊英雄 | — | 勇士建筑，冠军类 +1 |
| 恐虐神尊英雄 | — | 勇士建筑，冠军类 +1 |
| 纳垢神尊英雄 | — | 勇士建筑，冠军类 +1 |
| 奸奇神尊英雄 | — | 勇士建筑，冠军类 +1 |
| 色孽神尊英雄 | — | 勇士建筑，冠军类 +1 |
| 混沌术士 | 阴影、死亡、火焰、金属 | 神龛建筑，法师类 +1 |
| 纳垢混沌术士 | 死亡、纳垢 | 神龛建筑，法师类 +1 |
| 奸奇混沌术士 | 金属、奸奇 | 神龛建筑，法师类 +1 |
| 色孽混沌术士 | 阴影、色孽 | 神龛建筑，法师类 +1 |

同一座勇士建筑只贡献一次 +1，五种神尊英雄共用；同一座神龛建筑也只贡献一次 +1，四种混沌术士共用。印记英雄保留原版神恩晋升等获取条件，这张容量表不额外开放其直接招募。

艾查恩的「卓越冠军勇士」技能还提供冠军类容量 **+1**。其他角色技能、特性等加成按各自效果计算；本说明以可重复建设的建筑来源为主。

## 野兽人营地：3 种英雄

『独眼』卡扎克、『黑暗征兆』马拉戈、『影孽』魔古尔和『铜牛』陶诺斯加入艾查恩后，可在各自军队的野兽人营地建造下列建筑。需要扎营建设，容量加成归艾查恩全派系使用。

| 英雄 | 法术系 | 容量来源与所需营地主建筑等级 |
| --- | --- | --- |
| 嘶叫萨满 | 野兽、死亡、阴影、狂野 | Ⅱ「神选兽群·萨满焰坑」+1 → Ⅲ「神选兽群·萨满焚堆」+1 → Ⅴ「神选兽群·祭杀场地」+1；进入法师类容量 |
| 巨角公牛 | — | Ⅲ「神选兽群·火焰深井」+1 → Ⅳ「神选兽群·肉食储存点」+1；进入冠军类容量 |
| 战角兽 | — | Ⅲ「神选兽群·生皮图腾」+1；进入密探类容量 |

每条建筑序列到达表中首个等级时解锁对应英雄；嘶叫萨满的四系同时解锁。一座营地的上述三条建筑各提供对应容量 +1；升级不会把其中任一条的贡献提高到 +2。

## 诺斯卡军营：4 种英雄

『流浪者』乌弗瑞克、索隆格、『无信者』萨尔中的任意一位实际加入艾查恩后，可在艾查恩自己的黑暗要塞建设诺斯卡军事建筑。养伤中的已收服领主也计入；仅建立附庸关系不解锁建筑。

| 英雄 | 法术系 | 容量来源与所需主城等级 |
| --- | --- | --- |
| 巫术萨满 | 死亡、火焰、金属 | Ⅲ「混沌图腾」+1 → Ⅳ「血父祭坛」+1 → Ⅴ「萨满柴堆」+1；进入法师类容量 |
| 巨身狼人 | — | Ⅲ「黑暗祭品洞穴」+1；进入冠军类容量 |
| 沼栖妖贵族 | — | Ⅱ「迷雾沼地」+1 → Ⅲ「妖龙裂谷」+1 → Ⅳ「沐岚悬崖」+1 → Ⅴ「冰川通路」+2；进入符文匠类容量 |
| 沼栖妖降灾使 | 火焰、阴影 | Ⅳ「沐岚悬崖」+1 → Ⅴ「冰川通路」+2；进入使节类容量 |

每行从首个列出的建筑开始解锁英雄及其全部所列法术系。野兽围栏序列前两级不解锁巨身狼人；混沌生物序列到「沐岚悬崖」才解锁沼栖妖降灾使。

「冰川通路」一座建筑分别提供符文匠类 +2、使节类 +2，受损时分别降为 +1，成为废墟后不再提供容量。

## 混沌矮人军营：3 种英雄

阿斯特戈斯·铁手、『灰烬』德拉兹霍斯、『黑心』扎坦中的任意一位实际加入艾查恩后，可在艾查恩自己的黑暗要塞建设混沌矮人军事建筑。解锁条件与诺斯卡分别计算。

| 英雄 | 法术系 | 容量来源与所需主城等级 |
| --- | --- | --- |
| 半人牛陶鲁克 | — | Ⅱ「熔岩原野」+1 → Ⅲ「怪兽畜栏」+1 → Ⅳ「火焰飞地」+1 → Ⅴ「实验工坊」+2；进入冠军类容量 |
| 炼狱堡主 | — | Ⅱ「灰烬楼层」+1 → Ⅲ「矿石楼层」+1 → Ⅳ「钢铁楼层」+1；进入工程师类容量 |
| 恶魔铁匠术士 | 死亡、火焰、哈苏特、金属 | Ⅱ「恶魔锻铺」+1 → Ⅲ「火焰祭坛」+1 → Ⅴ「哈苏特巨窑」+1；进入法师类容量 |

每行从首个列出的建筑开始解锁英雄及其全部所列法术系。「实验工坊」的冠军类 +2 在受损时降为 +1，成为废墟后不再提供容量。

诺斯卡、混沌矮人直属仆从的城市数量影响对应军营兵种的普通招募费用减免，每族最多 50%；城市数量不提供英雄容量。

## 外部英雄模组：9 种英雄

本节来源要求同时使用相应外部模组。`daemon_portals.pack` 提供恶魔传送门及恶魔部队机制；下列英雄招募与容量加成由 **`woc_heroes_portals.pack`** 提供。Everchosen 主模组本身不额外给恶魔传送门添加英雄容量。

| 英雄 | 法术系 | 容量来源 | 附加条件 |
| --- | --- | --- | --- |
| 鲜血收割者 | — | 恐虐传送门Ⅲ、Ⅳ各 +1，Ⅴ +2；使节类 | 对应传送门 |
| 瘟疫使徒 | 死亡、纳垢 | 纳垢传送门Ⅲ、Ⅳ各 +1，Ⅴ +2；密探类 | 对应传送门 |
| 虹光惧妖 | 金属、奸奇 | 奸奇传送门Ⅲ、Ⅳ各 +1，Ⅴ +2；符文匠类 | 对应传送门 |
| 魅魔侍女 | 阴影、色孽 | 色孽传送门Ⅲ、Ⅳ各 +1，Ⅴ +2；工程师类 | 对应传送门 |
| 恐虐狂信徒 | — | 「警卫兵营」或「勇士大厅」每座 +1；符文匠类 | 已研究「牺牲祭坛」 |
| 纳垢狂信徒 | — | 「怪兽巢穴」每座 +1；使节类 | 已研究「腐烂祭坛」 |
| 奸奇狂信徒 | — | 「萨满寺庙」或「亵渎圣所」每座 +1；使节类 | 已研究「神秘旗帜」 |
| 色孽狂信徒 | — | 「轴心大厅」每座 +1；使节类 | 已研究「混响室」 |
| 杜鲁齐受祝者 | — | 「勇士大厅」每座 +1；符文匠类 | 拥有色孽「痛苦之潮」内容 |

传送门的数字表示传送门等级；其余为黑暗要塞建筑。狂信徒的科技条件同时影响表中招募开放与建筑容量加成。招募在对应行省开放，容量归全派系；升级同样只取当前建筑总值。

这些额度也按第一节的共享关系使用。例如，恐虐狂信徒与虹光惧妖共用符文匠类额度，鲜血收割者与纳垢狂信徒共用使节类额度。

## 容量测试包的额外设置

`everchosen_hero_capacity_test.pack` 为可选测试包。玩家艾查恩的单人超凡帝国新战役开场，按上述 28 种英雄各提供 1 格，汇入原有共享容量：

| 共享容量 | 开场额外增加 | 计数方式 |
| --- | --- | --- |
| 冠军类 | +8 | 五种神尊英雄、巨角公牛、巨身狼人、半人牛陶鲁克 |
| 法师类 | +7 | 四种混沌术士、嘶叫萨满、巫术萨满、恶魔铁匠术士 |
| 使节类 | +5 | 鲜血收割者、沼栖妖降灾使、纳垢／奸奇／色孽狂信徒 |
| 符文匠类 | +4 | 沼栖妖贵族、恐虐狂信徒、虹光惧妖、杜鲁齐受祝者 |
| 密探类 | +2 | 战角兽、瘟疫使徒 |
| 工程师类 | +2 | 炼狱堡主、魅魔侍女 |

这是额外加成，可以与建筑贡献相加。不同法术系不重复增加开场容量。测试包还让艾查恩从一级黑暗要塞主城起即可招募全部 28 种英雄、46 个子类型，不必先建对应军营；仍需正常付费和使用容量，不直接赠送英雄。

同包另有两种英雄的独立额度实验：

| 英雄 | 独立额度设置 | 法术系与占用规则 |
| --- | --- | --- |
| 魅魔侍女 | 合计 1 名 | 阴影、色孽共用这 1 格；养伤中仍占用 |
| 炼狱堡主 | 另计 1 名 | 与魅魔侍女分别计算；养伤中仍占用 |

这两种额度固定为 1，不随建筑数量增长；失去英雄后释放其独立额度。原版工程师类共享容量仍同时构成限制。独立额度在开场检查通过后启用；与主模组同用时，分类名后显示各自的「已用/上限」，顶部仍显示共享池数量。本局未启用独立额度时，测试包仍提供开场容量与主城招募功能。

其他英雄在测试包中继续使用六种共享容量。开场加成与独立额度实验仅用于玩家艾查恩的单人超凡帝国新战役；主城招募权限按艾查恩派系区分，也会影响其他战役、多人战役或电脑控制的艾查恩。

## 塔木尔可汗的六位氏族长

凯兹克、哀丧嚎叫、喀尔甘、格鲁克摩尔、凯扎克、伊萨尔由独立的 **Tamurkhan Chieftain Progression** 子模组处理，不包含在上述 28 种普通英雄及开场 28 格的计数中。

塔木尔可汗实际加入艾查恩后，按其当前等级补足对应人数。默认至少 1 位；达到 5、10、15、20、25 级时，目标总人数分别为 2、3、4、5、6。已有且养伤中的氏族长计入，只补缺少的人物。这条获取途径按塔木尔可汗等级决定人数，不靠增建军营触发；安装 MCT 时可以调整等级门槛与补充顺序。

其他玩法与使用条件见[功能说明](features.md)。
